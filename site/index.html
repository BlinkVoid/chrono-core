The problem

Sessions end. Context shouldn't.

AI-assisted work happens in sessions that evaporate. The reasoning behind a decision, the blocker you were mid-way through, the doc that contradicts the code — all of it lives in a scrollback buffer or nowhere at all.

# Monday morning, new session
$ chrono resume

Project: chrono-core · branch main
Decisions: resume scopes to current git branch by default
Blockers:  CI install fails on externally-managed Python (open)
Next:      tag the 0.1 release once fresh-clone install is verified

# One command before you close the laptop
$ chrono handoff --summary "scrubbed history, flipped repo public"

⏯ Branch-scoped resume

chrono resume returns the state that matters for the branch you're on — decisions, open blockers, next actions — with honest hidden counts across other branches.

🤝 Structured handoffs

Capture summary, files changed, verification runs, decisions, blockers, next actions, and risks as queryable records — not prose in a commit message.

🐛 Bug tracking, dogfooded

Per-project bug records with FTS search and lifecycle states. Chrono Core tracks its own development in its own database.

📋 Doc reconciliation

Deterministic review passes compare docs against canonical state and surface contradictions — explicitly heuristic, never pretending to be semantic understanding.

🔎 Cross-project search

Full-text search over captured observations spans every project in the workspace. Pattern ingestion and similarity mining included.

🔌 MCP server built in

Every capability is exposed as an MCP tool (chrono-mcp), so Claude Code, Codex, Kimi, or OpenCode can resume, hand off, and record decisions directly.

Install

One file, zero services

Requires Python 3.12+ and uv. State lives in a single WAL-mode SQLite database with ordered migrations — nothing to host, nothing to sync.

# Install the CLI + MCP server from source
uv tool install git+https://github.com/BlinkVoid/chrono-core.git

# Resume the current project's state
chrono resume

# Register the skill + MCP server with GearCore
chrono gearcore install-plan
